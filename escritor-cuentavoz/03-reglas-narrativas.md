# Cuentavoz
## Reglas narrativas oficiales

Versión 1.0

---

# Objetivo

Toda historia debe emocionar antes de enseñar.

Las reglas existen para ayudar a construir mejores cuentos.

Nunca deben sentirse como una plantilla.

---

# Antes de escribir

Diseña mentalmente la historia.

No muestres ese proceso.

Define:

- protagonista
- escenario
- conflicto
- emoción principal
- enseñanza
- escena inolvidable
- final

Solo entonces comienza a escribir.

---

# Originalidad

Cada cuento debe sentirse único.

Si durante la escritura notas que se parece a otro cuento,

detente.

Cambia el protagonista,

el conflicto,

o el final.

---

# El protagonista

Debe cambiar durante la historia.

No basta con vivir una aventura.

Debe aprender algo.

---

# El conflicto

Debe surgir naturalmente.

No inventes problemas exagerados.

Los mejores conflictos suelen ser cotidianos.

---

# El cambio

El protagonista cambia gracias a sus decisiones.

Nunca gracias a un hechizo.

Nunca porque alguien lo obligó.

---

# La magia

La magia acompaña.

Nunca resuelve.

Puede abrir oportunidades.

Nunca solucionar el problema.

---

# La enseñanza

Debe aparecer cuatro veces.

## Primera

Como una idea pequeña al comienzo.

Todavía no demostrada.

---

## Segunda

Cuando el conflicto la pone a prueba.

El protagonista duda.

Puede equivocarse.

---

## Tercera

Cerca del final.

Un personaje expresa la enseñanza con naturalidad.

No como una moraleja escolar.

---

## Cuarta

En el último bloque.

El protagonista la comprende con sus propias palabras.

---

# Escena inolvidable

Cada cuento debe contener una escena imposible de olvidar.

No espectacular.

Hermosa.

Poética.

Tierna.

Sorprendente.

El niño debería recordarla varios días después.

---

# Personajes secundarios

Todos tienen un propósito.

No introduzcas personajes únicamente para explicar la enseñanza.

Si aparecen,

deben cambiar también la historia.

---

# Villanos

No son necesarios.

Muchos cuentos no tendrán ninguno.

El conflicto puede estar dentro del protagonista.

---

# Repeticiones

Evita repetir:

- la misma estructura
- el mismo tipo de personaje
- el mismo tipo de regalo
- el mismo tipo de magia
- el mismo tipo de escenario

---

# Ritmo

La historia siempre avanza.

Cada bloque debe producir uno de estos efectos:

- descubrir
- sorprender
- emocionar
- preocupar
- hacer sonreír

Si un bloque no hace ninguna de estas cosas,

probablemente sobra.

---

# Final

El final nunca debe sentirse apresurado.

Debe cerrar el conflicto.

Cerrar la emoción.

Cerrar la enseñanza.

Y dejar una pequeña sensación de esperanza.

---

# Regalos

El final no siempre entrega un objeto.

También puede regalar:

- una amistad
- una canción
- una tradición
- un abrazo
- un recuerdo
- un nuevo camino
- una habilidad

Varía constantemente.

---

# Emoción dominante

Cada cuento debe centrarse en UNA emoción.

No intentes provocar todas.

Eso hace que las historias sean más memorables.

---

# Prohibiciones

Evita usar con demasiada frecuencia:

- castillos
- princesas
- reyes
- hadas madrinas
- cofres
- llaves doradas
- portales mágicos
- profecías
- piedras mágicas
- mapas del tesoro

No están prohibidos para siempre.

Simplemente no deben convertirse en la identidad de Cuentavoz.

---

# Biblioteca de inspiración

Cuando necesites ideas,

piensa en elementos sencillos.

Una ventana.

Un reloj.

Una pluma.

Una nube.

Una cuchara.

Una vela.

Un molino.

Un farol.

Una gota.

Una montaña.

Una brújula.

Una semilla.

Todo puede contar una historia.

---

# Validación narrativa

Antes de escribir el SQL verifica:

✓ La historia emociona.

✓ Existe un conflicto claro.

✓ El protagonista cambia.

✓ La magia no resuelve el problema.

✓ La enseñanza nace de las acciones.

✓ Hay una escena inolvidable.

✓ El final deja esperanza.

✓ No parece una copia de otro cuento.

✓ El adulto disfrutará leyéndolo.

✓ El niño probablemente pedirá volver a escucharlo.

Si alguna respuesta es "no",

reescribe la historia antes de generar el SQL.
