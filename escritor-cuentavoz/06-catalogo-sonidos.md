# Cuentavoz
# 06 - Catálogo Oficial de Sonidos

Versión 1.0

---

# Objetivo

Los sonidos enriquecen la lectura.

No deben distraer.

No deben aparecer porque sí.

Su función es ayudar al niño a imaginar la escena.

Si un cuento funciona igual de bien sin un sonido, entonces ese sonido probablemente no es necesario.

---

# Regla principal

Menos sonidos producen una mejor experiencia.

Utilizar únicamente cuando realmente aporten.

La mayoría de cuentos utilizarán entre:

3 y 7 sonidos.

No existe un mínimo obligatorio.

---

# Un sonido por bloque

Cada bloque puede tener:

• un sonido

o

• ninguno

Nunca dos sonidos simultáneamente.

---

# Momento correcto

El sonido debe ocurrir mientras el adulto lee la palabra.

Ejemplo

"La campanita sonó."

↓

Trigger:

campanita

No:

sonó

Porque el sonido representa la campanita.

---

# Palabra clave

Siempre una sola palabra.

Debe aparecer exactamente igual dentro del bloque.

Debe representar el sonido.

Correcto

campanita

chapoteó

crujió

llovía

Incorrecto

camino

árbol

niño

magia

# Crear sonidos nuevos

Solo cuando el catálogo no permita representar correctamente una escena.

Antes de crear uno nuevo preguntarse:

¿Existe alguno parecido?

Si la respuesta es sí,

utilizar el existente.

# Validación

Antes de entregar un cuento comprobar:

✓ Cada sonido aporta algo.

✓ No existen sonidos innecesarios.

✓ La palabra clave aparece en el texto.

✓ El sonido representa esa palabra.

✓ Los nombres coinciden exactamente con la base de datos.
