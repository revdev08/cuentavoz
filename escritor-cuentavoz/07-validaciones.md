# Cuentavoz
# 07 - Validaciones Oficiales

Versión 1.0

---

# Objetivo

Antes de entregar cualquier cuento, la IA debe realizar una validación completa.

No debe asumir que todo está correcto.

Debe revisar el cuento como si fuera un editor.

---

# Validación narrativa

## Historia

✓ Tiene principio.

✓ Tiene desarrollo.

✓ Tiene final.

---

## Conflicto

✓ Existe un conflicto claro.

✓ El conflicto evoluciona.

✓ El protagonista toma decisiones.

---

## Moraleja

✓ Aparece al inicio.

✓ Se pone a prueba.

✓ Se expresa cerca del final.

✓ Se reafirma en el cierre.

---

## Personajes

✓ Todos tienen propósito.

✓ Ninguno sobra.

✓ El protagonista cambia.

---

## Magia

✓ Existe solo si aporta.

✓ Nunca resuelve el problema.

---

## Emoción

✓ Existe una emoción dominante.

✓ El final deja esperanza.

---

## Originalidad

Comparar mentalmente con cuentos anteriores.

Si se parece demasiado,

reescribir.

---

# Validación técnica

✓ SQL válido.

✓ Compatible con PostgreSQL.

✓ Compatible con Supabase.

✓ Historia buscada mediante slug.

✓ Variables declaradas.

✓ Variables utilizadas.

✓ No existen variables huérfanas.

✓ Todos los bloques tienen imagen.

✓ Los sonidos existen.

✓ Las palabras clave son correctas.

✓ Cada palabra clave supera la prueba de sonido: aparece en su bloque y
  describe literalmente el audio asignado, no solo la imagen o el contexto.

✓ Las rutas son coherentes.

✓ No existen bloques repetidos.

✓ El SQL es idempotente.

---

# Validación literaria

Leer mentalmente el cuento.

Comprobar:

✓ Fluidez.

✓ Musicalidad.

✓ Belleza.

✓ Claridad.

✓ Ritmo.

Si una frase suena forzada,

reescribirla.

---

# Validación infantil

Preguntarse:

¿Un niño de cuatro años podría seguir esta historia?

Si no,

simplificar.

---

# Validación para el adulto

Preguntarse:

¿Un padre disfrutaría leyéndola?

Si no,

reescribir.

---

# Validación de imágenes

Cada bloque debe imaginarse como una ilustración.

Si un bloque no produce una imagen clara,

mejorarlo.

---

# Validación de repetición

Comparar con los cuentos existentes.

No repetir:

- protagonista
- estructura
- regalo
- moraleja
- guía
- escena inolvidable

---

# Validación final

Antes de responder todas las respuestas deben ser SI.

□ SQL correcto.

□ Historia emocionante.

□ Enseñanza natural.

□ Personajes memorables.

□ Ritmo adecuado.

□ Sonidos coherentes.

□ Variables suficientes.

□ Assets consistentes.

□ Final satisfactorio.

Solo entonces entregar el cuento.
