# Cuentavoz
# 08 - Registro de Recursos Narrativos

Versión 1.0

---

# Objetivo

Este documento evita que los cuentos empiecen a parecer iguales.

Después de publicar cada cuento debe actualizarse este registro.

La IA debe consultarlo antes de escribir uno nuevo.

---

# Qué registrar

Cada cuento debe añadir una fila con:

- título
- protagonista
- variables
- escenario principal
- emoción dominante
- moraleja
- quién inicia el cambio
- quién expresa la moraleja
- escena inolvidable
- regalo o cierre
- recurso mágico utilizado
- sonidos nuevos creados

# Reglas

Antes de escribir un cuento nuevo revisar esta tabla.

Evitar repetir:

- el mismo protagonista
- el mismo conflicto
- el mismo tipo de final
- el mismo regalo
- la misma moraleja
- el mismo guía
- la misma estructura narrativa

---

# Repetición aceptable

Pueden repetirse escenarios generales.

Ejemplo

Bosque.

Montaña.

Río.

Pero deben sentirse completamente distintos.

---

# Repetición no aceptable

No hacer:

"Otro objeto mágico ayuda al protagonista."

"Otro animal sabio aparece."

"Otro regalo brillante."

"Otro árbol mágico."

Aunque cambien los nombres.

---

# Biblioteca de inspiración

Si una categoría empieza a repetirse demasiado,

buscar inspiración en:

Objetos cotidianos

Fenómenos naturales

Estaciones

Instrumentos musicales

Comidas

Profesiones

Lugares pequeños

Elementos del cielo

Elementos del agua

Elementos del viento

Así el universo crecerá de forma orgánica.

---

# Estadísticas recomendadas

Cuando existan muchos cuentos mantener también:

Número de cuentos por moraleja.

Número de protagonistas humanos.

Número de protagonistas animales.

Número de protagonistas objetos.

Número de protagonistas elementos de la naturaleza.

Número de cuentos con magia.

Número de cuentos sin magia.

Esto permitirá detectar repeticiones antes de que ocurran.

---

# Regla de oro

Cada nuevo cuento debe aportar algo que todavía no exista en Cuentavoz.

No basta con cambiar nombres.

Debe ampliar el universo.

Cuando un niño escuche el cuento número 100,

debe sentir la misma sorpresa que sintió con el primero.
